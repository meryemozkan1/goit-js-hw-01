# GoIT JavaScript Homework #1 (Module 1)

This project is the first JavaScript homework assignment within the GoIT Full Stack Developer program. It focuses on basic JavaScript syntax, variable declarations, arithmetic operations, template literals, and functions.

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-js-hw-01/)

## 🛠️ Tasks Included
- **Task 1:** `makeTransaction` — Calculates total price for ordered droids and returns formatted string.
- **Task 2:** `getShippingMessage` — Computes shipping costs including delivery fees per country.
- **Task 3:** `getElementWidth` — Calculates total element width considering content, padding, and borders (`border-box`).

## 🛠️ Technologies & Tools Used
- **JavaScript (ES6+):** Functions, template literals, parsing numbers (`parseFloat`).
- **Prettier:** Code formatting.
- **Git & GitHub:** Version control and GitHub Pages deployment.
